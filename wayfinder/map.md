# Wayfinder map — moved to GitHub Issues

The canonical map is now
[issue #8](https://github.com/AndrewGodlewsky/Dataverse-to-Azure-Web-App/issues/8)
(label `wayfinder:map`); tickets are its sub-issues. A session claims a ticket by
assigning it, resolves it with a resolution comment, closes it, and updates the map
issue's Decisions-so-far. The frontier = open, unblocked, unassigned sub-issues.

Research assets stay in this repo under `wayfinder/research/`, linked from the issues
that produced them.
