The seven hops

  1. Front endHTTPS terminated by Azure.
  2. Easy AuthNo session → Entra sign-in → cookie. Your code sees nothing yet.
  3. Forward to the one portIdentity arrives as X-MS-CLIENT-PRINCIPAL* headers.
  4. Node serves the shellHTML + JS bundle. Charts render empty.
  5. /api, same originNo CORS by construction.
  6. Cache miss → tokenApp credential → Entra → bearer token for Dataverse.
  7. Dataverse answersRole checked, rows returned, BFF caches and shapes.

Never happens: browser → Dataverse. On any option.

The trap

WEBSITES_PORT is not injected into the container (App settings reference). The three 8080s above line up because they were each set to 8080 — not because one feeds another.
