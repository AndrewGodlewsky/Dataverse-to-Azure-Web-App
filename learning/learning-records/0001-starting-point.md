# Starting point: new to both Azure and Dataverse

Stated at workspace creation (2026-08-08): no prior familiarity with either platform —
Azure resource groups, App Service, managed identities, and Dataverse tables, security
roles and the admin center are all new. The mission is nonetheless operational (deploy
and run this system solo), not academic.

**Implications**: lessons must define vocabulary on first use and cannot lean on portal
navigation being familiar. But because the goal is operational, every concept should be
introduced *attached to a thing that already exists in this repo* — a file, a figure, a
command — rather than taught in the abstract first. Depth comes from the mission, not
from platform tours.
